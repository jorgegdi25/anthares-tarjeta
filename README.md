# ANTHARES Landing

Landing mobile-first en Next.js para ANTHARES, pensada para abrirse desde un QR.

## Ejecutar

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run start
```

## Personalización rápida

- Reemplaza el video del hero en `public/media/anthares-hero.mp4`.
- Ajusta enlaces y textos principales en [app/page.tsx](/Users/jorgegonzalezmejia/Desktop/Anthares/app/page.tsx).
- Si luego cuentan con fotografías reales de producto, cambia los assets SVG actuales en `public/images/`.
